# Simulador de hipotecas

Simulador de cuota, TAE y coste total de una hipoteca, con:

- ITP de Andalucía (3,5 % para menores de 35 años en primera vivienda; 7 % general).
- Ahorro necesario: entrada + tasación + notaría + registro + ITP.
- Vinculaciones con su bonificación y coste anual.
- Campos de porcentaje que admiten coma decimal.

Abrir: https://antonioelectronica.github.io/simulador-hipotecas/

Optimizador (plazo, LTV y vinculaciones que minimizan intereses): https://antonioelectronica.github.io/simulador-hipotecas/optimizador.html

Basado en el simulador público de habitacion.com, con modificaciones propias.
